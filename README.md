Теперь это полноценное веб-приложение, которое открывается по ссылке с телефона и ноутбука.

## Локальный запуск

1. Установи Node.js 18+.
2. В папке проекта выполни:

```bash
npm install
```

3. Создай `.env` по примеру:

```bash
    copy .env.example .env
```

4. Вставь свой ключ в `.env`:

```env
ANTHROPIC_API_KEY=...
```

5. Запуск:

```bash
npm start
```

Открой `http://localhost:3000`.


## Как открыть с телефона в одной Wi-Fi сети


1. Узнай IP ноутбука (например `192.168.1.15`).
2. Запусти сервер `npm start`.
3. На телефоне открой: `http://192.168.1.15:3000`.


## Как открыть из любой сети (интернет)


Самый простой вариант — деплой на Render/Railway/Vercel (Node app):


- Подключи GitHub репозиторий.
- Build command: `npm install`
- Start command: `npm start`
- Добавь переменную окружения `ANTHROPIC_API_KEY`.
- После деплоя получишь URL вида `https://your-app.onrender.com`.


Эта ссылка будет работать и на телефоне, и на ноутбуке без VS Code.
